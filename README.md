# AI Music Generation

This project generates a simple piano melody using Python.

## Technologies Used
- Python
- Streamlit
- Music21
- NumPy

## How to Run
1. Install requirements: pip install -r requirements.txt
2. Run: streamlit run music_generator.py
3. Click on Generate Music to create a MIDI file.
